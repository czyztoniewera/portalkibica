# portalkibica
Platforma informacyjna dla kibiców klubu piłkarskiego z panelem administracyjnym CMS. Aplikacja ASP.NET Core MVC umożliwiająca zarządzanie aktualnościami, profilami zawodników oraz terminarzem meczów. System wspiera publikację i administrację treści w nowoczesnym, responsywnym środowisku webowym.
